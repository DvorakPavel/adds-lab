# AD DS Lab — Active Directory Built From Scratch

A Windows Server 2025 Active Directory Domain Services forest, built from nothing on Oracle
VirtualBox and documented task by task.

Preparation for **Microsoft Applied Skills: Administer Active Directory Domain Services
(APL-1008)**.

**Related projects:**
[sc300-entra-lab](https://github.com/DvorakPavel/sc300-entra-lab) — 33 tasks covering the full
SC-300 exam scope via the Entra portal and PowerShell ·
[entra-graph-lab](https://github.com/DvorakPavel/entra-graph-lab) — 15 tasks of Microsoft Graph
API automation

> This repository is in progress. The full overview will be written once the lab is complete.

## How this repository is organised

| Path | Contents |
|---|---|
| `notes/` | One note per task — goal, what was done, result, lessons learned, references |
| `evidence/` | One folder per task — PowerShell transcripts, `dcdiag` and `repadmin` output, GPO and RSoP reports, LDIF exports |
| `scripts/` | Reusable PowerShell. Commands run once stay inline in the note; anything run again lives here |

Every note carries a **References** line listing the Microsoft Learn documentation the task was
validated against.
